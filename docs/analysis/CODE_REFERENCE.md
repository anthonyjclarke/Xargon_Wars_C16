# Generated Code Reference

## Scope and Method

Generated by `scripts/analyze_codebase.py` from the verified build and the preserved disk sources. Line numbers are the logical lines of each disk file (CR-separated, counting from 1). PRG bytes are allocated from the assembler listing, so a module total includes code, tables and text; it is not a function size. Direct transfers are operands written in JSR, JMP and branch instructions: fall-through, interrupt vectors, the `WHJUMP` computed branch and runtime operand patches are not in that list. A symbol can name a branch point or data, not only a callable routine.
